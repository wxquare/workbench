## 当前实现

- 父 Run 预算与用量结算已实现。模型调用额度仅有一次时保留给最终汇总，专家不调用；不足时生成确定性 partial。
- DeepSeek 文本、工具、JSON、流和用量探针曾连接真实服务；运行时使用受部署绑定约束的密钥引用与端点。
- `dod.v4` 提供可检查点恢复的主图。RCA/inspection 在部署显式配置模型、MCP 与范围权限，且 Run 固定了可用只读工具时，可使用受 Guard、模型和工具预算约束的 LangChain diagnosis 循环；在证据和跨专家验证不完整时返回 partial。模型的自由文本不会直接成为业务结论。
- `dod.v5` 的 QA 路径接入受信 knowledge 专家身份与 LangChain 工具循环；本地 SQLite/Worker 与实际本地 DoD MCP 服务及合成知识上游已验证范围、父预算、证据读取、撤权与崩溃恢复。模型自由文本不会作为已验证结论，当前结果仍为 partial。
- 诊断循环的本地集成覆盖真实 SQLite 和 Worker，使用受控工具和替身模型；每个子任务使用独立检查点命名空间，已派发工具使用稳定调用标识。专家完成、父图提交前崩溃的恢复测试不重复调用。

## 未完成

- 知识、监控、Trace 的企业调用尚未证明授权范围，仍默认拒绝；真实知识问答、引用可访问性及固定 commit 代码分析尚未验收。
- Code 专家、跨专家可信身份、并发、知识答案验证和完整证据合成尚未接入；当前 QA 和 diagnosis 不代表完整 M2。Skill 分资源按需加载已实现；Claude/脚本适配仍待完成。
- 真实 Docker/MinIO 验收、独立 Runner 协议与心跳、产物导出和生产下载签名装配尚未完成。
- 自动审批曾拒绝外部 MCP 验收命令：非生产目标、认证、团队/区域范围和查询内容尚未明确授权。该命令没有执行。
