## 关键契约

- Agent Profile 的工具是固定 `VersionRef`。页面只显示已发布、只读取的
  `knowledge_search`，保存只会修改 Agent 草稿，发布仍需单独确认。
- 工具对话最多绑定 4 个工具、单次运行最多 4 次工具执行。模型工具调用的逻辑 ID
  由运行与持久化消息位置派生；恢复不会用随机 ID 重发已发送请求。
- 已发送或预留冲突会转为 `partial`，不会自动重试外部模型请求。
- 工具回答固定以“以下回答基于所列工具返回的结果，未经独立校验”开头；
  成功工具证据必须能从 Run 证据端点读取。失败、空结果、超时、截断和拒绝都保留
  各自状态，不能写成“正常”。
- 工具对话历史只读取同一 Thread、同一 Agent、同一知识范围和同一证据权限下的
  已完成轮次。摘要篡改、范围变化或撤权会使该历史轮次退出模型上下文。
- 工具评估以 `tool-conversation-eval-v1` 单独校验与评分。规则只检查调用序列、
  allowlist、终态、工具依据行和证据可见性；恶意输出、截断完整性等仍标记待人工评审。
